# AI支援タスク詳細化システム 詳細設計書

## 1. データベース設計 (Phase 1)

アプリケーションの基礎となるデータベースのスキーマを定義します。

### 1.1. `projects` テーブル
プロジェクトの情報を管理します。

| カラム名      | データ型         | 説明                                   |
| :------------ | :--------------- | :------------------------------------- |
| `id`          | `BIGINT` (PK)    | プロジェクトID (主キー)                |
| `name`        | `VARCHAR(255)`   | プロジェクト名                         |
| `description` | `TEXT`           | プロジェクトの説明                     |
| `context`     | `TEXT` または `JSON` | プロジェクトコンテキスト（技術スタック等） |
| `created_at`  | `TIMESTAMP`      | 作成日時                               |
| `updated_at`  | `TIMESTAMP`      | 更新日時                               |

### 1.2. `tasks` テーブル
タスクの情報を管理します。

| カラム名       | データ型         | 説明                                     |
| :------------- | :--------------- | :--------------------------------------- |
| `id`           | `BIGINT` (PK)    | タスクID (主キー)                        |
| `project_id`   | `BIGINT` (FK)    | 関連するプロジェクトのID                 |
| `parent_id`    | `BIGINT` (FK)    | 親タスクのID（階層構造のため）           |
| `title`        | `VARCHAR(255)`   | タスクのタイトル                         |
| `description`  | `TEXT`           | タスクの詳細な説明                       |
| `status`       | `VARCHAR(50)`    | タスクの状態（例: '未着手', '進行中', '完了'） |
| `created_at`   | `TIMESTAMP`      | 作成日時                                 |
| `updated_at`   | `TIMESTAMP`      | 更新日時                                 |
